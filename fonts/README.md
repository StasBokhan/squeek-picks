# Fonts

Served from this site, so the page needs no font CDN. All four are under the SIL Open Font
License 1.1 (the LICENSE files here), copied unchanged from their Fontsource npm releases:

- `hanken-grotesk.woff2`: Hanken Grotesk, latin, weight axis (@fontsource-variable/hanken-grotesk 5.3.0). The page's text.
- `courier-prime-400.woff2`, `courier-prime-700.woff2`: Courier Prime, latin (@fontsource/courier-prime). Numbers on the ticket, and the share pictures.
- `doto.woff2`: Doto, latin, weight and roundness axes (@fontsource-variable/doto 5.3.0). The till display's dot-matrix digits.
- `anton.woff2`: Anton, latin (@fontsource/anton). The rubber stamps.
